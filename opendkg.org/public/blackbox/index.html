Guardian Agent Blackbox, by Umanitek.

An open-source runtime guard for AI agents. It watches what an agent is about to do, flags risky actions, and can block confirmed threats when you turn that on.

Third-party · Live Umanitek · MIT · Open source

Part of the Axiom package

A separate guardrail, with a separate author.

Guardian Agent Blackbox is included in the Axiom package as the optional agent guardrail. It is built and maintained by Umanitek, not by OpenDKG.

That distinction matters. Blackbox has its own repository, license, documentation, release process, and limits. Axiom’s firewall work is separate from Blackbox’s runtime checks.

Sees
Prompts, tool calls, commands, files, packages, and skills an agent handles.
Can do
Flag risky actions and block confirmed threats when block mode is enabled.

Signed threat signals only when community sharing is enabled.

What it watches

Six categories of risk, described by Umanitek.

These are the vendor’s descriptions, not an independent OpenDKG audit. Read Umanitek’s documentation for the current rule set and coverage.

Prompt injection

Hidden instructions buried in pages, files, or tool output.

Vulnerable dependencies

Packages with known gaps or malicious versions.

Dangerous commands

Shell actions that delete, exfiltrate, or alter systems.

Sensitive file access

SSH keys, tokens, environment files, and credentials.

Secret exposure

Real keys handled or shipped off the machine.

Suspicious skills

Newly installed skills that misbehave.

How it responds

Audit first. Blocking is opt-in.

Blackbox runs in audit mode by default. It records findings and shows them in a local dashboard; it does not stop the agent unless you enable block mode.

In block mode, a block requires the configured severity threshold and a trusted source. Community and heuristic findings are flag-only. The project documents these boundaries in its own README.

Read the current Blackbox README ↗

It fails open

A Blackbox fault does not stop the agent. That keeps work moving, but it is a limit, not a guarantee. Plan for the guard to be unavailable.

No blanket prompt-injection immunity is claimed.

What you need

A host, a guard, and a local node.

Umanitek documents Hermes as the host that works out of the box; OpenClaw workspaces use a bundled bridge. The guard uses a local DKG node for its threat graphs.

Installation and configuration belong to Umanitek’s project. This page does not reproduce those steps, and it does not claim that every agent host is supported.
