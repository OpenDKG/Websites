AI agent security · Public builds (active development)

Axiom

For people who run AI agents on Windows, macOS or Linux. AI agents can read files, run commands and reach the network. Axiom is meant to show what those agents do, let you set limits, and keep that monitoring on your own machine. Windows x64 has a current installer and portable build; Ubuntu 24.04 amd64 and Intel macOS builds are previews. It is in active development, not audited or production-ready.

Local AI gateway · v0.5.0 (active development)

OpenDKG Desktop

Native Tauri and Rust AI gateway on 127.0.0.1:4820 that connects Cursor, Claude Code, Codex and Windsurf. Adds 3-layer agent memory, Privacy Shield, Spend Guard and self-custody OT-RFC-27 wallets on Base, with zero telemetry.

Knowledge vault · v0.5.0-pre (active development)

DKG Graph Local

Zero-gas neuro-symbolic knowledge vault powered by OriginTrail DKG v10.1.2 Working Memory and a WASM Graph Computer. Gives 12 AI clients verified sub-graphs and Privacy Split proof certificates over loopback MCP :3847.

Security assurance · RC 0.1.0 (active development)

VerityTrail

Local-first security assurance lab for Windows x64 built on .NET 10 and Avalonia. Combines immutable SHA-256 snapshots, CWE SAST and CycloneDX 1.5 SBOMs with isolated WSL2 or VM checks and read-only Blackbox-guarded AI reviews.

Shared knowledge · Live

DKG Swarm

For AI assistants that support MCP, an open standard for connecting them to outside data. DKG Swarm adds a shared memory of findings with their sources attached, built on OriginTrail, so an assistant can reuse earlier work instead of starting from zero. Reading is free; contributing needs approval.

Telegram moderation · Live

TRACaBot

For Telegram group admins. TRACaBot flags impersonators and scam patterns, keeps evidence for review, and can share reviewed findings with other groups. With the admin rights and settings you grant, it can delete messages or remove people on its own. Removing someone as they join is a separate choice you turn on.
